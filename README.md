# 🖥️ OS Resource Manager

A web-based Operating System Resource Manager designed to simulate and manage system resources efficiently through an interactive and user-friendly interface.

---

## 🚀 Features

✅ Process Management  
✅ Resource Allocation Visualization  
✅ Interactive Dashboard  
✅ Memory & Process Tracking  
✅ Clean and Responsive UI  
✅ Dynamic Frontend Functionality  

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Python

---

## 🎯 Project Objective

This project was developed to demonstrate concepts of Operating System resource management through an interactive and practical web application. It helps visualize how processes and system resources can be managed efficiently using a clean web-based interface.

## ▶️ How to Run the Project

1. Clone or download the repository
2. Open the project folder
3. Run the Python server:

```bash
python server.py

```

4. Open the generated local server link in your browser
